## About the Project

This website is my personal portfolio and digital CV.  
It is designed to present my professional journey, technical skills, internship experience, projects, and achievements in a visually engaging way.

The site includes:
- A strong hero section with animated introduction.
- About section with summary, stats, and contact links.
- Experience timeline.
- Featured projects.
- Skills and technologies.
- Achievements and positions of responsibility.
- Contact section with email, phone, GitHub, LinkedIn, and LeetCode.

## Features

- Responsive single-page layout.
- Smooth scrolling navigation.
- Animated cursor effect.
- Scroll-triggered section reveal animations.
- Typed text animation in the hero section.
- Interactive project card effects.
- Modern dark theme with neon accent styling.
- Fast and lightweight static site.
- Easy to deploy on GitHub Pages, Netlify, or Vercel.

## Getting Started

To run this project locally:

1. Clone the repository:
```bash
git clone https://github.com/NandaniSharma04/CV.git
```

2. Open the project folder:
```bash
cd CV
```

3. Open `index.html` in your browser.

If you want a local server, you can use:
```bash
npx serve
```
or the Live Server extension in VS Code.

## Deployment

You can deploy this website using:

- GitHub Pages
- Netlify
- Vercel

For GitHub Pages:
1. Push the code to GitHub.
2. Go to repository settings.
3. Enable GitHub Pages from the main branch.
4. Your site will be live at your GitHub Pages URL.
